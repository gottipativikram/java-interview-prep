# Java Full-Stack Interview Prep

An offline-friendly study site with 166 interview questions on Core Java, Java 8 Streams, Spring Boot, Security, Microservices, SQL and Angular. Every question has a concise answer and an in-depth answer, and the site includes 25 diagrams and 5 narrated topic videos.

- `index.html` is the full site, with search, company filters (TCS, Hexaware, G2Healthcare and others) and progress tracking.
- `Topic-*.html` are single-topic pages.
- `Interview-Guide-*.pdf` are printable versions of the answers.
